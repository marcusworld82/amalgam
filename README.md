# Amalgam Motion Frontend

A frontend-only premium motion concept for Amalgam.

## Repository structure

```text
.
├── app
│   ├── globals.css
│   ├── layout.tsx
│   └── page.tsx
├── public
│   └── botanical-capsule.jpeg
├── next-env.d.ts
├── next.config.mjs
├── package.json
├── README.md
└── tsconfig.json
```

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Stack

- Next.js 14
- React 18
- TypeScript
- GSAP + ScrollTrigger
- CSS motion system
- Responsive and reduced-motion aware

The capsule image should be located at `public/botanical-capsule.jpeg`.
